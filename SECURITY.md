# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, detection bypass, or false negative in Composer-Audit-ZeroTrust:
1. Please do **NOT** open a public issue.
2. Email the maintainer directly at: `55404783+Anton-Barinov@users.noreply.github.com` or create a private GitHub Security Advisory.
3. Include sample `composer.json` / `composer.lock` or malicious code fixtures.

We investigate all reports promptly and issue updates within 24 hours.
